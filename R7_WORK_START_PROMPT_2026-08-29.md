## Главные решения

- Активен **один** продукт: обычная HiveOS-обёртка GigaHash ZK.
- Текущая версия официального бинарника: `v1.9`, CUDA `12.9`.
- Текущий HiveOS-пакет: `gigahash-1.9.0.tar.gz`.
- Split NOCK+PRL закрыт, удалён из текущего проекта и GitHub Releases. Не восстанавливать его без нового прямого решения пользователя.
- SRBMiner, PearlHash и PRL больше не входят в проект.
- Официальный бинарник проприетарный. Мы не изменяем CUDA-ядро; мы разрабатываем HiveOS-обёртку, загрузку, проверку, статистику, сборку и релизную инфраструктуру.
- Следующее обновление проекта делается только после выхода нового официального GigaHash-бинарника.
- Для операций на ригах пользователь предпочитает пошаговый режим: одна команда — один результат — следующая команда.
- Не делать `push`, GitHub Release, удаление assets или изменение рабочих ригов без явного разрешения пользователя на конкретную операцию.
